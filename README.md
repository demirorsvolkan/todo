# Todo App

Todo uygulamasının uygulama kaynak kodlarını içerir.

## İçerik

- `frontend/` → Frontend uygulaması
- `backend/` → Backend uygulaması
- `Jenkinsfile` → CI/CD pipeline
- `docker-compose.yml` → Local geliştirme ve test

## Infrastructure

Uygulamanın Kubernetes ve Helm yapılandırmaları ayrı repository'dedir:
